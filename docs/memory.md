# Project Memory

## Background

Sahaara AI was developed to assist helpline operators with real-time analysis of conversations. The system originated as a distress detection tool and evolved to address the broader scope of victim safety and vulnerability as defined by the National Human Rights Authority (NHAA).

## Contextual Notes

- **Demo Data:** The system requires a robust set of synthetic and scripted demonstration cases to test various distress levels and languages.
- **Indian Context:** The system is specifically designed for the Indian subcontinent, with a focus on linguistic diversity (Hindi, Marathi, English) and cultural contexts of abuse/coercion.
- **Research Goal:** The ultimate goal is not just to assist operators, but to build a benchmark dataset that validates multimodal AI approaches for safety assessment.
